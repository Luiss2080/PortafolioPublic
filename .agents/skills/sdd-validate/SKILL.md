# SDD Validate Skill

Usa esta skill para la Fase 5 del SDD.
- Correr auditoría de código, validación de estilos visuales.
- Ejecutar suite de pruebas (`npm run test`).
- Revisar que no haya legado ni código inactivo antes de hacer commit.
