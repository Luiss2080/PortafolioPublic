# UI/UX Designer Skill

Garantiza la creación de interfaces premium, accesibles y consistentes.

## Design System
- **Tokens**: Definir paletas de colores (primarios, secundarios, neutros), tipografías, espaciados y sombras de forma global.
- **Consistencia**: Componentes reusables estandarizados. Nunca usar colores o medidas "mágicas" en línea, todo debe venir del sistema.

## Interacciones y Estética
- **Micro-animaciones**: Transiciones fluidas en hovers, clicks, y entrada/salida de componentes (Framer Motion).
- **Feedback**: El usuario siempre debe saber el estado de sus acciones (Spinners, Skeletons, Toasts).
- **Glassmorphism / Dark Mode**: Soporte nativo para temas modernos según la tendencia y requerimientos del usuario.

## Accesibilidad (a11y)
- Contraste de colores que cumpla el estándar WCAG AA mínimo.
- Jerarquía visual clara (H1, H2) para lectores de pantalla.
