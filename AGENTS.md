# AGENTS.md — Portafolio Estándar

## Proyecto
Portafolio estándar, corporativo y adaptable a cualquier tipo de cliente o industria.
Desarrollado en React 18, Vite 5, Tailwind CSS y Framer Motion con arquitectura modular de componentes.

## Comandos
- Iniciar desarrollo: `npm run dev`
- Compilar producción: `npm run build`
- Previsualizar build: `npm run preview`

## Estilo y convenciones
- React funcional con hooks y componentes desacoplados en `src/components/`.
- Estilizado con Tailwind CSS usando tokens y clases de utilidad estandarizadas.
- Idioma del contenido: Español formal, ejecutivo, moderno y claro.
- Animaciones fluidas mediante Framer Motion y `react-parallax-tilt`.

## Reglas
- Sigue rigurosamente el principio de SDD: **"Que el código diga la verdad y la especificación también"**.
- Lee [docs/constitution.md](file:///c:/laragon/www/PortafolioEstandar/docs/constitution.md) y la spec activa en [docs/specs/001-portafolio-estandar.md](file:///c:/laragon/www/PortafolioEstandar/docs/specs/001-portafolio-estandar.md) antes de modificar cualquier componente.

- Mantener la armonía estética: fondo obsidiana profundo, superficies de cristal sutil y acentos en azul zafiro/cobalto ejecutivo.
- Cada cambio en código debe mantener sincronizadas las especificaciones y el listado de tareas en [docs/specs/tasks.md](file:///c:/laragon/www/PortafolioEstandar/docs/specs/tasks.md).
