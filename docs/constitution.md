# Constitución del Proyecto: Portafolio Estándar

1. **Stack**: React 18, Vite 5, Tailwind CSS 3.4, Framer Motion, Lucide Icons.
2. **Propósito**: Portafolio estándar, corporativo, sobrio y adaptable a cualquier tipo de cliente o industria, sin lenguaje ni encasillamiento exclusivo en desarrollo de software puro.
3. **Estética y UI/UX**: Minimalismo premium empresarial (fondo oscuro obsidiana/grafito mate `#0A0D14`, bordes micro-luminosos, acentos ejecutivos), tipografía equilibrada (Inter/Syne) y micro-animaciones fluidas (60 FPS). Variantes cromáticas por cliente: los acentos pueden ajustarse a la identidad aprobada en la spec activa (Spec 002: esmeralda + dorado champán para el perfil de marketing y mercados financieros).
4. **Calidad y Accesibilidad**: Contraste WCAG AA, diseño responsivo estricto (móvil, tablet, desktop) y semántica HTML5 adecuada.
5. **Veracidad del Contrato (SDD)**: "El código dice la verdad y la especificación también". Ningún componente refleja datos falsos o contradictorios con la spec.
6. **Límites**: No introducir librerías pesadas innecesarias. Mantener compatibilidad con Vite sin errores de consola ni advertencias de lint.
